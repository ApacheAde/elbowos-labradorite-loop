# Labradorite Loop

Full-colour Python 3 neon light-cycle arcade for ElbowOS.

Steer a cyan cycle that leaves a glowing trail. Collect gold sparks. Avoid walls, your own ribbon, and the magenta rival. Last one looping wins.

Left / Right (or A / D) turn. R restart.

## Play

```
pip install -r requirements.txt
python3 labradorite_loop.py --play
```

## Record a 9:16 reel

```
python3 labradorite_loop.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
